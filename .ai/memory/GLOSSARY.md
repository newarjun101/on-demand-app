# Glossary

- **MMK**: Myanmar Kyat, the default integer currency (`DEFAULT_CURRENCY=MMK`).
- **X-App-Origin**: Custom HTTP header (`CUSTOMER_WEB`, `WORKER_WEB`, `ADMIN_WEB`) identifying the calling frontend.
- **Boost**: Paid visibility promotion for a `WorkerProfile` using tiers configured in `PlatformConfig.boostTiers`.
- **KYC**: Know Your Customer verification (`KycDocument`, `WorkerVerificationStatus.APPROVED`) required before a worker can submit quotes.
- **RBAC**: Role-Based Access Control for admins (`AdminRole`, `Permission`, `RolePermission`, `UserRole`).
